# numbers-cli

A [Claude Code](https://claude.com/claude-code) plugin for full **Apple Numbers** control via AppleScript.

See [`numbers-plugin/README.md`](numbers-plugin/README.md) for installation, usage, and the complete command reference.

## Quick Start

```bash
git clone https://github.com/marcelrgberger/numbers-cli.git
cd numbers-cli

# Install into Claude Code
mkdir -p ~/.claude/plugins/cache/local/numbers-cli/1.0.0
cp -R numbers-plugin/* ~/.claude/plugins/cache/local/numbers-cli/1.0.0/

# Then register and enable in settings — see numbers-plugin/README.md
```
